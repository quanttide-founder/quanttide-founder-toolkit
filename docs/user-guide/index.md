# 用户指南

工具箱把「靠目录命名约定组织的 Markdown 文档集合」读成语义模型：日志、档案、洞察、路线图、小说、观察站，读出来是结构化数据，人才能往里写、AI 才能往外用。这组文档面向使用方，从装包到跑通一条完整流水线。

## 页面导航

- [快速开始](quickstart.md)：装包、跑通第一个解析示例
- [解析仓库](parsing.md)：装载 memory 与 fiction 仓库，读懂产出的模型
- [规则与工作流](rules.md)：规则文件怎么描述「一种文档怎么读」，工作流怎么组装三个动词
- [编排与状态流](orchestration.md)：四步流程、三步提炼，读终态还是订阅状态流

框架定位与设计动机不在本组文档里，见[工具箱总述](../index.md)。

## 语言切换

工具箱是 Dart 与 Rust 双实现，行为逐条对齐。所有因语言而异的内容（安装命令、代码、API 签名）以标签块呈现，同一页内点一次即全文联动：

```{tab-set}

:::{tab-item} Dart
:sync: dart

~~~dart
print('当前标签：Dart');
~~~

:::

:::{tab-item} Rust
:sync: rust

~~~rust
println!("当前标签：Rust");
~~~

:::
```
```

正文与图示只写一份，两种语言共用。
